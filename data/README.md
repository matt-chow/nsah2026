# data/

Everything in this directory is **published** with the static site (`web/vite.config.ts` uses it
as `publicDir`). Put only validated, size-bounded products here.

| Path | Contents | Committed |
|---|---|---|
| `manifests/manifest.schema.json` | JSON Schema generated by `parallax schema`. Do not hand-edit. | yes |
| `manifests/*.json` | Observation manifests (contract: `docs/DATA_CONTRACT.md`) | yes |
| `fixtures/` | **SIMULATED** test data generated by `parallax make-fixture` | yes |
| `processed/` | Validated cutouts (FITS) and display PNGs from real SPHEREx data | small sets only |

Disposable downloads and caches go to `<repo>/.cache/parallax/` (gitignored, never published).

Budget: keep `data/` under **25 MB** total and any single file under **5 MB**. Check with
`scripts/check.ps1`.
