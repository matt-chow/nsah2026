## Direction contract

THESIS: The sky is the evidence, and every claim reads like an astronomical telegram: position, epoch, flux, uncertainty, status UNCONFIRMED. This refuses the default arrangement of glowing KPI tiles over a nebula wallpaper.

OWN-WORLD: The ground is night ink (#0b0d12) with cool graphite rails. Bulletin paper (#e9e4d8) is used for report text, and a single sodium-amber signal (#f2a33a) marks selection and candidates. The difference map is a blue/orange diverging scale, with glyph markers so it never relies on colour alone. Type pairs a grotesk UI face with a monospace for every number, set in fixed ephemeris columns. Rules are 1px hairlines and corners are square.

STORY: The visitor arrives under a slow starfield with a single sentence about what SPHEREx sees, then enters the workspace. They blink two epochs, switch to the difference map, open a candidate, and read why it is "needs follow-up" rather than a discovery.

FIRST VIEWPORT: The intro is a full-bleed starfield with the title, a one-line purpose and an "Open the workspace" button. The workspace has a top bar (field preset select, RA/Dec search, Tour). The left two-thirds holds the canvas with a mode toolbar (Blink / Overlay / Difference) and the timeline underneath. The right rail lists candidates, then the evidence report.

FORM: Astronomical telegram/circular bulletin, number 3 on my ordered list. seed:bda28d9c8d493b0e. Signature move: each candidate's evidence is set as a telegram report block, with fixed-width columns and a stamped status line.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
